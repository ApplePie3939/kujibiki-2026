# 学園祭くじ引きアプリ 要件・実装計画

## 1. 目的と利用環境

学園祭のシステム科模擬店（ポテト・唐揚げ販売）で使う、来場者向けのくじ引きアプリを開発する。

- ネラボの一体型 Windows PC で利用する。
- インターネットに接続しないローカル環境でも動作する Web アプリとする。
- 賞の在庫と当選結果を端末内で管理する。

## 2. 機能要件

### 必須機能

- 利用者が「くじスタート」を押すと抽選できる。
- 抽選中はガラポンまたはルーレットが動く演出を表示する。
- 抽選結果として A賞、B賞、C賞、D賞のいずれかを表示する。
- A賞が当選した場合は、ほかの賞より目立つ派手な演出を表示する。
- 賞ごとの在庫数を超えて当選させない。
- A賞・B賞の残数を画面に表示し、残数が 0 になった賞は表示を消す。

### 管理機能

- 賞ごとの初期在庫数、当選確率、表示名などを後から変更できる。
- 2日目の開始時に在庫と当選数を初期状態へ戻せる。
- リセット前に誤操作を防ぐ確認を表示する。
- 賞ごとの残数と当選数を確認できる。

## 3. 画面フロー

1. 待機画面で A賞・B賞の残数と「くじスタート」ボタンを表示する。
2. 「くじスタート」を押すと、連続操作を一時的に無効化し、抽選中演出を表示する。
3. 抽選ロジックで在庫のある賞から結果を決定する。
4. 結果画面で当選した賞を表示する。A賞は専用の強い演出を再生する。
5. 一定時間後または操作後に待機画面へ戻り、残数表示を更新する。
6. 管理画面では設定の編集、当選状況の確認、日次リセットを行う。

## 4. 実装タスク

- **基盤構築**: Windows PC 上でローカル起動できる Web アプリの構成を用意し、ネットワーク接続なしで必要な素材と処理が完結するようにする。
- **抽選ロジック**: 賞別の在庫・確率を基に結果を決定し、当選時に在庫と当選数を更新する処理を実装する。
- **画面・演出**: 待機、抽選中、結果、管理の各画面を作成し、A賞用の特別演出を追加する。
- **設定・リセット**: 賞の設定編集、残数・当選数の表示、確認付きの日次リセットを実装する。
- **動作確認**: オフラインの Windows PC で起動、抽選、設定変更、リセットを確認する。
- **提出物準備**: 動作画面の画像または動画を撮影し、1,000文字以内の説明・アピール文を作成する。

## 5. 受け入れ条件とテスト

- 各賞は設定した在庫数を超えて当選しない。
- A賞・B賞の残数が正しく表示され、残数 0 の賞は表示されない。
- 日次リセット後、賞ごとの残数と当選数が初期値に戻る。
- インターネット未接続のネラボ一体型 Windows PC でアプリを起動し、抽選できる。
- 実際に動作している画面の画像または動画を用意する。
- アプリの説明・アピール文を 1,000文字以内で用意する。

賞の初期数量、当選確率、賞の内容、結果画面の演出デザインは、運用前または運用中に管理画面から調整できるものとする。
