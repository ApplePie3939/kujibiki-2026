# くじ引きアプリ・ハッカソン メモ

## 目的

学園祭のシステム科模擬店（ポテト・唐揚げ販売）で使う、くじ引きアプリを個人で開発する。

## 必須機能

- くじ引きができる
- ローカル環境（回線なし）で動作する
- ネラボの一体型 Windows PC で動作する

## あると良い機能

- 2日目にリセットできる（両日で当たり数を同数にするため）
- 当たりの数などを後から調整できる
- A賞・B賞・C賞・D賞を用意する
- A賞が当たったときの派手な演出
- 「くじスタート」でガラポンやルーレットが動く演出
- A賞・B賞の残数を表示し、残数が0になった賞は表示を消す

## 提出物

- 実際に動作している画面の画像または動画（必須）
- アプリの説明・アピール文（1,000文字以内、必須）
- 公開 URL（任意）
- GitHub URL（任意）
