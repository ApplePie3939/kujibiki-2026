# アプリの説明・アピール文

学園祭のポテト・から揚げ模擬店で使う、オフライン対応のくじ引きアプリです。来場者は大きな「くじスタート」ボタンを押すだけで抽選に参加でき、ガラポンとルーレット風の演出のあと、A〜D賞の結果が表示されます。特にA賞は紙吹雪と色鮮やかな背景で大当たりを印象的に伝えるため、会場を盛り上げます。

賞ごとの在庫と当選数は端末内に保存され、在庫がなくなった賞は抽選対象から自動的に外れます。画面にはA賞・B賞の残数だけを分かりやすく表示し、残数が0になると表示も消えるため、スタッフが在庫を即座に把握できます。管理画面からは賞名、初期在庫、抽選確率を運用中でも変更でき、各賞の残数・当選数も確認可能です。2日目の開始時には、確認画面を経て在庫と当選数を初期状態へ戻せます。

HTML、CSS、JavaScriptだけで構成し、外部ライブラリや通信を使用していません。Windows PCでファイルを開くだけで利用できるため、インターネット接続がない会場でも安心して運用できます。
