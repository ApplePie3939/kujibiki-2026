# kujibiki-2026

学園祭向け・オフライン対応のくじ引きアプリです。

## 起動方法

`index.html` をWindowsのブラウザで開いてください。外部ライブラリや通信は不要です。

抽選結果と設定は、そのPCのブラウザ内（LocalStorage）に保存されます。管理画面から賞名、初期在庫、抽選確率（重み）、残数・当選数を確認できます。

管理画面を開くには、4桁のパスコードが必要です。初期コードは `2026` です。必要に応じて [app.js](app.js) の `ADMIN_PASSCODE` を変更してください。
